# psy-berdnikova.ru — рабочая версия

Копия живого сайта, снята 20.11.2026 с хостинга Timeweb (аккаунт cu130571, сервер vh466.timeweb.ru, папка `~/yulia-berdnikova/public_html`).
Сделала помощница Юлии, содержимое актуально и согласовано. Дальше работаем с этой версией, а не со сборкой из `..\Сайт\`.

- `index.html`, `styles.css`, `script.js` — одностраничник, без сборки и без серверной части.
- `assets/` — картинки, `assets/documents/` — дипломы и сертификаты (PDF + JPG).
- `index.htm.bak-20261116-140824` — старая резервная копия, которая лежит на хостинге; на сайте не используется.
- На хостинге рядом есть служебная `cgi-bin`, её не трогать.

Выкладка — только после согласования, одним подключением (иначе хостинг блокирует IP).

## Юридические документы (20.11.2026)

- `privacy.html` — политика конфиденциальности, `consent.html` — согласие на обработку ПДн. Редакция `2026-11-20-2` (номер также в `data-consent-version` у `<html>` в index.html); при изменении состава данных, целей или получателей — новая редакция в обоих файлах.
- Реквизиты ИП (ИНН, ОГРНИП) — в подвале `index.html` и на страницах документов. Дату и место рождения, адрес регистрации не публикуем.
- `consent.js` — уведомление о cookie на всех страницах. Яндекс Метрика: вписать номер счётчика в `METRIKA_ID` и обновить раздел 8 в `privacy.html`.
- Шрифты подключены локально (`fonts.css`, `fonts/`), а не с Google Fonts — чтобы IP посетителей не уходил за границу.
- `api/lead.php` — приём заявок «Уточнить запись» (Ольга Авдашина): письмо на help@psy-berdnikova.ru и журнал согласий `~/yulia-berdnikova/private/consents.jsonl`. Работает только на хостинге с PHP; на GitHub и локально форма показывает телефон центра.
