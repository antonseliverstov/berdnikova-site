# Сайт-визитка Юлии Бердниковой

Статический сайт без сборки: HTML, CSS и немного JS. Чтобы посмотреть, откройте `index.html` или запустите любой локальный сервер в этой папке. Пути относительные, поэтому сайт работает из любой папки на хостинге.

## Структура

| Путь | Что там |
|---|---|
| `index.html` | страница |
| `privacy.html` | политика ПДн, пока заглушка |
| `css/style.css` | стили; цвета и шрифты задаются переменными в `:root` |
| `js/config.js` | **все настройки**: номер, мессенджеры, цены, флаги |
| `js/main.js` | логика: подстановка из конфига, меню, карта, cookie, подгонка подписи |
| `fonts/` | Cormorant Garamond 500, Manrope 400/500/600, лицензия OFL |
| `img/` | фото в AVIF, WebP и JPEG, ширины 480, 960 и 1600 |
| `скриншоты/` | вид страницы на 1440 и 375 px |

## Как поменять данные

Всё меняется в `js/config.js`, вёрстку трогать не нужно.

- **Номер:** `phone: '+79XXXXXXXXX'`. На сайте он появится как ссылка `tel:` в формате «+7 900 000-00-00».
- **Мессенджеры:** `telegram`, `whatsapp`, `max` — полные ссылки. Пока ссылки нет, кнопка неактивна. Кнопка «Написать Юлии» ведёт в мессенджер из `primary`.
- **Заглушки:** `placeDetails`, `days`, `duration`, `ivfDetails`, `routeParking`, `routeGate`, `routeEntrance`, `routeFloor`, `legal`. Строка заменяет заглушку «[уточнить]», `null` оставляет заглушку на месте.
- **Цены:** заполните `prices: [['Консультация в кабинете', '0 000 ₽'], …]` и поставьте `showPrices: true`.
- **Подходы и награда:** `showMethods: true` и `showAward: true`. Включать только после согласования (лист 07 брендбука).

## Метрика

Укажите номер счётчика в `metrikaId`. Счётчик загрузится только после того, как посетитель нажмёт «Согласен» в баннере cookie. Других внешних скриптов на сайте нет. Яндекс Карта подгружается только по нажатию «Показать карту».

## Фото

Исходники лежат в `../Фото/`, их не трогаем. Чтобы заменить фото, положите в `img/` файлы с тем же именем во всех трёх форматах и размерах. Например, `portrait-hero-480|960|1600.avif|webp|jpg`. Нужные кадры: вход, парковка и табличка, они встанут в блок «Как добраться» вместо «Фото скоро». Знак Феникс ставим только на тёмные блоки.

## Перед публикацией

- [ ] Заполнить конфиг (номер, мессенджеры, корпус и кабинет, дни, реквизиты).
- [ ] Вставить тексты политики ПДн и cookie в `privacy.html` (готовит Антон).
- [ ] В `robots.txt` и `sitemap.xml` заменить «ДОМЕН» на адрес сайта, в `index.html` поставить абсолютный `og:image` и `canonical`.
- [ ] Согласовать с Юлией тексты блока «Обо мне» (в коде помечены `<!-- черновик -->`).
- [ ] Убрать `<meta name="robots" content="noindex, nofollow">` из `index.html` и открыть `robots.txt` (Allow: /): сейчас черновик закрыт от поисковиков.
- [ ] Прогнать Lighthouse (мобильный режим) на рабочем домене.
