# Сайт Юлии Бердниковой

Многостраничный статический сайт по ТЗ `TZ_site_Yulia_Berdnikova.docx`. Страницы собираются из данных скриптом:

```
python _build/build.py
```

Главный принцип: неподтверждённые сведения на сайт **не выводятся**. Пока поле в `_build/site.json` пустое (`null`, `false`, `[]`), соответствующий блок не публикуется. Заглушек «уточнить» на сайте нет.

## Страницы

| URL | Что там |
|---|---|
| `/` | главная: первый экран, доверие, запросы, форматы, первая встреча, обо мне, кабинет, FAQ, запись |
| `/about/` | о Юлии |
| `/requests/` | хаб запросов |
| `/requests/anxiety/`, `relationships/`, `grief/`, `self-harm/` | тематические страницы |
| `/online/` | психолог онлайн |
| `/services/` | форматы и стоимость |
| `/first-session/` | как проходит первая встреча |
| `/office-tula/` | кабинет, фото, маршрут |
| `/faq/` | частые вопросы |
| `/booking/` | запись |
| `/privacy/` | политика ПДн (краткая, до текста юриста) |
| `404.html` | страница не найдена |

Страниц `/journal/`, `/consent/`, `/terms/` и `/requests/ivf/` нет: для них пока нет содержания или согласованных документов.

## Что включается данными (`_build/site.json`)

| Поле | Что появится |
|---|---|
| `phone`, `telegram`, `whatsapp`, `max`, `primary` | кнопки «Записаться на приём» в шапке и на всех страницах, блок записи внизу, ссылки в подвале. Пока каналов нет, кнопок записи нет нигде |
| `days` (+ `hours`) | часы «дни, 9:00–21:00». Без дней на сайте стоит «По предварительной записи» |
| `placeDetails`, `route` | корпус, этаж и кабинет; шаги маршрута: `[["Парковка", "…"], …]` |
| `yandexMapUrl`, `gisMapUrl` | кнопки карт. Нужны ссылки на **точную точку** организации, а не поиск |
| `prices`, `duration`, `payment`, `cancellation` | стоимость, длительность, оплата, перенос и отмена (на главной, в «Форматах», в FAQ) |
| `ivf` | карточка «Заключение перед ЭКО» |
| `showMethods`, `methods`, `education` | подходы и образование на главной и в «Обо мне» |
| `showReputation`, `showAward` | ссылка на ПроДокторов с рейтингом и датой проверки; премия в блоке доверия (3-е место, не «победа») |
| `legal` | реквизиты в подвале |
| `domain` | canonical, абсолютный og:image, индексация, sitemap и robots с доменом. Пока поля нет, сайт закрыт от поисковиков |
| `metrikaId` | Яндекс Метрика. Загружается только после согласия на cookie; цели `contact_<канал>` |

Тексты страниц правятся в `_build/build.py` (списки `REQUESTS`, `FAQ`, `FORMATS` и шаблоны страниц).

## Доступность

- Фокус: графитовая обводка на светлом фоне, золотая на тёмном. `scroll-padding-top` не даёт липкой шапке перекрыть элемент в фокусе.
- Меню: `aria-expanded` и `aria-controls`. При открытии фокус переходит на первый пункт; Esc закрывает меню и возвращает фокус; закрывается и кликом мимо.
- FAQ на нативных `details`/`summary`. Карточка запроса целиком кликабельна, но в ней одна ссылка.
- Хлебные крошки, один H1 на странице, `alt` у всех фото, ссылки в новую вкладку подписаны для экранного диктора.
- Cookie: компактная плашка, кнопки «Разрешить аналитику» и «Только необходимые» одинаковые по виду.

## Перед запуском на домене

1. Заполнить `site.json`, указать `domain`, собрать.
2. Подключить Яндекс Вебмастер и Google Search Console, отправить `sitemap.xml`.
3. Сверить имя, адрес, телефон и часы с Яндекс Бизнесом, 2ГИС и ПроДокторов.
4. Проверить разметку валидатором и Lighthouse на рабочем домене.
